Main git commands

  • git status - команда яка відображає поточний стан змін та файлів
  • git branch - команда яка показує список гілок в репозиторії
  • git add - команда яка ндексує вказаний файл для наступного коміту
  • git push - команда яка авантажує всі зміни локальної гілки до віддаленого репозиторію
  • git checkout - команда для перемикання між гілками
